# tools/blender

Headless Blender scripts that author 3D assets procedurally and export them into a game's
`assets/generated/`. Blender lives on the **Mac Studio**.

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b -P tools/blender/<script>.py -- <args>
```

## Conventions

- Every script takes its parameters as CLI args after `--`, so a mesh is fully reproducible from its
  manifest entry. No magic constants baked into the script body.
- Build geometry procedurally. Apply textures generated by `tools/artgen/gen.sh`.
- Export `.glb` for Godot, `.fbx` for Unreal. Z-up → engine conversion is the script's job, not the
  importer's.
- Record each output in the game's `assets/manifest.json` with `"tool": "blender"`, plus `script` and
  `args` in place of `prompt`.
- Keep polycounts honest — these have to hit 60 fps.

Scripts get added here as each game needs them.
